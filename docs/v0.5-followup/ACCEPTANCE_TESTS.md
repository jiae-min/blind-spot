# Claude 구현 후 수동/자동 인수 테스트

1. 모든 케이스에서 상단 ‘긴급 도움’ 버튼을 질문 없이 사용 가능.
2. 단기 위험/긴급성 질문은 건너뛸 수 있음. 가정폭력·성폭력 위치 정보도 선택 사항이고 GPS 요구 없음.
3. 단기는 의료·숙식·식사·긴급 비용을 포함하며, 신청·심사가 7일을 넘을 수 있다는 표기 유지.
4. 장기는 문항 순서가 JSON과 동일: 가정폭력 7, 성폭력 7, 가족돌봄 8, 생계·교육 기본 5 + 조건부 2.
5. 어려움 문항의 제목이 ‘현재 겪고 있는 어려움이 있나요?’이고, `괜찮아요`는 배타 선택.
6. 지원 분야 선택 직후 **해당 선택지 바로 아래** 정보가 표시됨; 이후 답변이 바뀌면 신청 조건/추천이 재평가됨.
7. 지역/나이 미응답으로 모든 제도가 사라지지 않음; 모르면 ‘추가 확인 필요’로 처리.
8. ‘신고 원하지 않음/서류 없음’이 일반 지원 전체를 강제 제거하거나 경찰 신고/서류 제출을 선행 조건으로 권하지 않음.
9. 하단 제목은 정확히 ‘긴급 연락처와 도움말’. 전화번호·시간·말하기 예시·전달 내용·대안이 한 섹션에 있음.
10. **연락처 숨김 충돌**: 문서의 `REQUIRES_OWNER_DECISION`을 확인하고 합의 없이 신고 의사로 자동 숨김 규칙을 변경하지 않음.
11. `서울특별시/서울특별시/중랑구` 기본 `seoul-north`, 경기 센터 없음.
12. `서울특별시/서울특별시/도봉구` 기본 `seoul-north`, 추가 `gyeonggi-northeast`.
13. `서울특별시/서울특별시/강서구` 기본 `seoul-south`, 추가 `gyeonggi-central`·`gyeonggi-northwest`.
14. `경기도/성남시/분당구` 기본 `gyeonggi-south`, 아동형은 성폭력 관련 적합한 경우에만 `gyeonggi-child` 후보.
15. 경기 선택 시 서울 센터가 기본/추가 후보로 나오지 않음.
16. 서울 25개 구, 경기 31개 시·군 및 시내 구별 세트 중복·누락 검사.
17. 아동형 센터를 모든 성인 응급지원의 1순위로 노출하지 않음.
18. 센터 공식 주소·전화·운영시간·대상·장소를 게시 전 재확인. 확인 실패 시 `미확인` 처리.
19. 화면에 ‘실제 가장 가까움/이동 N분’ 표시하지 않음(교통 검증 없음).
20. 단기→장기 연결 및 민감 응답 미보관·무회원 접근 등 기존 원칙 유지.
