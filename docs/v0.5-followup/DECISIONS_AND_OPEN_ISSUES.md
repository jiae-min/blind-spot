## 2. 이전 대화에서 어시스턴트가 제안한 초안 — 재검토 대상

- 4개 케이스의 구체적인 단기·장기 문항과 선택지(데이터에 수록)는 사용자에게 제시되었지만 문구 전체가 최종 승인된 상태로 간주하면 안 됨.
- 긴급 1문항이라는 정책과 폭력 케이스의 추가 ‘현재 위치 확인’ 사이에는 **단기 필수 질문 1개 + 선택적 위치 정보 1개**라는 해석을 명시함.
- 경기 31개 시·군과 세부 일반구를 서울·경기 11개 센터에 연결한 표는 **실제 최단 이동시간 검증 전**. 화성 4개 구 등 행정구역 최신성도 공식 검수 필요.
- 일부 지역은 동일 시 안에서도 이동시간이 다르므로, 구 단위로 배정하더라도 ‘최단거리’ 표현 금지.

## 3. 충돌 1 — 신고를 원하지 않으면 연락처 숨김?

- **초기 사용자 명시:** `지금은 경찰에 신고할 생각이 없어요`를 선택하면 하단 연락처 세션 숨김. 상단 긴급 도움 버튼은 유지.
- **이후 어시스턴트 검토:** 신고 거부와 상담기관 연락 거부는 다름. 신고 거부 시 신고 중심 행동을 기본 추천에서 제외하되 상담·보호시설 연락처까지 숨기지 않는 방식을 권고. 사용자는 이후 두 가지를 명시적으로 구별하는 최종 조작방식을 확정하지 않음.
- **현재 단기 플로우 문제:** 단기 사전질문에서 신고 의사 질문을 삭제했으므로, 단기에는 자동으로 연락처 섹션을 숨길 입력값이 없음.
- **안전한 구현 지시:** 현재 확정된 사실은 상단 긴급 버튼 상시 유지, 하단 섹션 제목·위치·사용자에 의한 표시 제어. 신고거부 입력만으로 전체 섹션을 자동 숨길지 여부는 **결정 필요**로 분리. 임의로 구현하지 말 것. 장기 신고 의사에 따라 ‘신고’ 행동 추천 우선순위를 낮추는 것은 가능.

## 4. 충돌 2 — 위치/추천 정확성

- 사용자는 행정구역 매핑 방식만 원하며 GPS 추적이나 매번 직선거리 계산은 원하지 않음.
- 어시스턴트의 과거 답변은 일부 매핑을 ‘추천’이라고 표현했지만, 실제 교통 이동시간 검증이 없어서 최적 매칭을 입증한 것은 아님.
- 구현은 **정적 연결 후보**로 한정하고 거리 순위는 미확인 표시. 법률·안전·의료 관련 정보를 부정확한 최단거리 주장으로 포장하지 말 것.

## 5. 기계 검증으로 확인할 수 없는 사항

센터의 2026-11-07 실제 운영 여부, 주소와 긴급/지속 상담 전화번호, 아동형 지원 대상 세부 조건, 보호시설 이용 조건, 지역별 진짜 최단 방문경로. 최신 공식 근거를 개별 확인 후 게시해야 함.
