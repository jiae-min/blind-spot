## 2. 데이터 연결 방식

```
case_questionnaires.json ──▶ questionnaire.ts (선택지 ID: 분야ID.번호)
                                  │
content/*.json (승인 원고) ──helpOptions──▶ 선택 항목 바로 아래 ResultCard
                                  │            └ conditions·needs ↔ 지역·나이·신고·어려움 답 → 상태·순서만 변경
center_directory.json ─┐
centers/verified.json ─┼▶ centers.ts ──▶ CenterMatch (지역 키 → 기본/추가/아동형 센터)
center_region_mapping ─┘                   └ 공식 확인 전 센터 = 공개 빌드에서 1366 연결 안내로 대신
```

- 지역 키는 원본 그대로 `서울특별시/서울특별시/중랑구`, `경기도/성남시/분당구`, `경기도/구리시`.
- 브라우저로 보내는 건 지금 페이지의 질문(서버에서 그려 둠)과 서울·경기 연결표 72줄(약 6KB)뿐. 다른 케이스 질문은 받지 않음.
- 답은 화면 안에서만 씀. 저장·URL·분석 전송 없음, 뒤로 가기로 돌아오면 비움.

## 3. 아직 안 된 것 · 결정이 필요한 것

**운영자 결정 필요**
1. 신고 거부 시 하단 연락처 자동 숨김 (`DECISIONS_AND_OPEN_ISSUES.md` §3, `REQUIRES_OWNER_DECISION`) — 구현하지 않음. 지금은 사용자가 '이 구역 접기'로만 접을 수 있고, 상단 '긴급 도움'은 항상 보임. 장기 '신고할 생각이 없어요'는 신고가 필요한 원고의 순서만 뒤로 미룸.
2. 이전 성폭력 3문항(경과시간·약물) 유지 여부 — 새 설계와 겹쳐 꺼 둠.
3. 화면용으로 붙인 질문 제목 2개: 가정폭력 단기 바로가기 "지금 어떤 상황에 가까우신가요?", 가족돌봄·생계교육 단기 지역 "지역별 기관을 찾고 싶다면 지역을 골라 주세요" (원본에 제목 없음).
4. 위험 응답 → 긴급번호 연결 대상: '지금 위험하거나 위협받고 있어요'(가정폭력)·'지금 신체적으로 위험하거나 위협받고 있어요'(성폭력) → 112, '돌보는 가족에게 갑작스러운 응급상황'(가족돌봄) → 119. 서비스 편집 제안.
5. 성폭력·가족돌봄·생계교육은 공개 빌드에서 여전히 '제작 중' (D-022). 미리보기에서 검토 후 `cases.ts`의 `ready`를 바꾸면 공개.
6. 질문 문구 전체는 원본 상태 `proposal_requires_owner_review` 그대로.

7. 지역 질문은 기존 디자인대로 서울·경기 두 버튼만 둠 (D-040). 원본 장기 '지역' 질문의 나머지 15개 시·도와 '지역을 고르지 않을래요'는 화면에서 빠짐 — 고르지 않으면 건너뛴 것으로 처리.

**자료가 없어 비어 있는 것**
- 선택지 아래 '관련 제도' — 공개 승인된 원고가 아직 0건이라 모든 항목에 "확인된 제도 정보는 아직 게시 전" 안내만 나옴. 원고에 `helpOptions`를 달면 바로 채워짐.
- 해바라기센터 이름·번호 — 11곳 모두 재검증 전이라 공개 빌드에서는 1366 안내로 대신 (미리보기에서는 '공식 확인 전' 표시와 함께 보임).
- 서울·경기 외 시·도는 시·군·구 목록과 센터 연결이 없음 → 시·도까지만 받고 1366 안내.
- 은둔 청년은 패키지에 질문이 없어 그대로 '제작 중'.

**받은 자료에서 발견한 불일치·재검증 항목**
- 생계·교육 장기 `welfare` 질문의 `conditionalOn`에 `school_fee`가 있는데, 이건 단기 분야 ID라 장기에는 없음 → 지금은 `income`·`housing`만 실제로 동작. `education`을 뜻한 것인지 확인 필요.
- 연결표 맨 위 상태는 `NOT_VERIFIED_FOR_TRAVEL_TIME_OR_NEAREST`, 각 줄은 `PROPOSED_NOT_DISTANCE_VERIFIED` — 둘 다 '거리 검증 전'이라 화면 처리는 같음.
- 서울해바라기센터 주소: 대학로 101(원 대화) vs 대학로 95(센터 홈페이지).
- 경기남부해바라기센터 번호: 031-216-1117 vs 031-215-1117(지속지원 번호 가능성).
- 경기북서부해바라기센터: 지속지원 장소(화정로 65-1)가 따로 있을 수 있음.
- 경기북동부해바라기센터: 소재 구 정보 없음.
- 아동형 센터(서울·경기)의 이용 나이·대상·운영시간.
- 화성시 4개 구 등 행정구역 최신성, 서울 접경 경기 센터의 교통 접근성.
