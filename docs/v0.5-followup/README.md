# Blind Spot — v0.5 이후 대화 후속 변경분

**기준일:** 2026-11-07  
**수록 범위:** 마지막 `BlindSpot_가정폭력_단기장기_Claude_통합자료_v0.5_2026-11-07.zip` 제공 *이후*에 주고받은 대화 내용만 반영.  
**형태:** 기존 코드·v0.5 자료에 적용할 **변경 명세(delta)**. 기존 ZIP 전체나 이전의 원시자료를 재첨부한 독립 완성 데이터셋이 아님.

## 읽는 순서
1. `CLAUDE_전달문.txt` — 그대로 Claude에 전달할 메시지
2. `docs/CHANGE_SPEC.md` — 결정 및 UI/데이터/분기 요구사항
3. `docs/DECISIONS_AND_OPEN_ISSUES.md` — 확정된 사용자 요구 vs 어시스턴트 제안, 충돌/미검증
4. `data/case_questionnaires.json` — 가정폭력·성폭력·가족돌봄·생계교육 단기·장기 질문과 하위 선택지
5. `data/recommendation_rules_delta.json` — 적용 규칙
6. `data/center_directory.json` — 서울 5/경기 6개 센터 기본 정보(모두 게시 전 재검증 대상)
7. `data/center_region_mapping.json` / `.csv` — **서울 25구 + 경기 31시·군(일반구 분리)** 정적 매핑 1차 제안
8. `qa/ACCEPTANCE_TESTS.md` — 구현·콘텐츠 검수 체크리스트

## 안전한 활용
- `case_questionnaires.json`의 문항은 합의 중인 UX/카피 초안입니다. 모든 문항이 전문기관 검증 설문은 아닙니다.
- `center_region_mapping.json`의 지역→센터 연결은 후속 대화의 **제안안**이지 실제 최단거리 검증자료가 아닙니다. `mappingStatus`를 반드시 유지하세요.
- 센터 전화·주소·운영시간은 과거 대화 기반 초안입니다. 게시 전 공식 기관에서 확인하세요.
- `v0.5`의 구 질문 구조(단기 6/장기 4) 및 `two_weeks` 분기보다 이번 후속 대화의 **단기 위험 1개(폭력 케이스 + 선택적 위치) / 장기 7~8개 / 7일 기준**이 최신 설계입니다.
- 민감정보, 신고 의사, 청소년 피해 등은 단정적인 자격/행동 추천을 금지합니다.

## 자동 검증 범위
- JSON 구문·참조 ID
- 서울 25구 1회씩 기본 센터 배정
- 경기 31개 시·군 존재 및 구별 키 중복 검사
- 센터 ID가 11개 중 하나인지 여부
- **실제 교통·거리·지원 자격 및 기관 운영 여부는 자동 검증하지 않았습니다.**
